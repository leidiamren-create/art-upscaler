# 中文使用说明

## 第一次打开

1. 便携版首次使用需要主程序、AI 引擎和模型三个 ZIP；把它们解压到同一个位置，合并为同一个 `ArtUpscaler` 文件夹
2. 打开该文件夹，双击 `启动素材清晰工坊.cmd`。保留启动窗口，浏览器会显示本地中文界面
3. 如果没有自动打开网页，将启动窗口中完整的本地网址复制到浏览器。网址含临时访问令牌，不要公开分享
4. 用完后在页面点“退出程序”。若系统或安全软件阻止运行，请先核对来源与提示，不要关闭安全防护

便携包不要求另装 Python 或 CUDA，不需管理员权限；必须有兼容 Vulkan 的 GPU 和驱动。CPU 实验模式不保证可用，程序不会自动降级到 CPU。

## 先试一张

选择原图文件夹；输出位置必须是原图文件夹以外的已有文件夹，留空则放到原文件夹旁边。建议先用 CUnet、温和降噪、长边 2048、分块 128，点击“先试一张”。检查线条、脸部、渐变和深浅背景下的透明边缘，再开始批量。

每次任务先做小图引擎自检；自检失败时不处理原图。开始时会重新扫描，以当时的文件为准。“先试一张”处理扫描到的第一张，不保证该图片是你最想检查的图片。

## 输出和日志

- 每次创建新的 `原目录名_AI_日期时间` 目录，不修改原图
- 保留子目录和完整原文件名，如 `角色/hero.jpg` 变成 `角色/hero.jpg_AI.png`
- 结果目录只放成品 PNG，不生成对比图片、缩略图或 `_report`
- JSON / CSV 处理报告单独保存在工具 `logs/` 中，可点“打开报告”
- 工具目录不可写时，报告保存会警告，但已经能正常处理的成品仍会输出
- 坏图单独记错，继续处理后续图片；取消会保留已完成结果，重跑创建新目录
- v0.1.0 以前的对比图和旧结果不会被自动删除

日志可能包含本机完整路径和文件名。反馈问题前请去掉这些隐私内容，不要提交含访问令牌的启动网址。

## 尺寸、颜色与透明度

长边 2048 表示统一尺寸：1536×1024 → 2048×1365；比目标大的图片也会缩小。支持目标长边 64–8192，按比例取整，不能强制输出方图。

需要放大时先进行所需的 2 倍 AI 推理，再重采样到目标尺寸；多轮放大只在第一轮按所选强度降噪。原图较大时先缩到目标，再作 1 倍降噪。关闭降噪且无需放大时只调整尺寸，报告会如实注明。upconv 做 1 倍降噪时改用 CUnet。

透明度不会交给 AI 降噪，而是单独缩放。尺寸不变的 1 倍处理保留原透明度；全透明图仅调整尺寸。算法尽量减少边缘黑边，但不保证所有素材无瑕疵。

按 EXIF 方向纠正，尽量转为 sRGB。动画、多页图、16 位/HDR 不支持并会报错。单图限制 2400 万像素，AI 中间图 3600 万像素，放大最多 32 倍。显存不足可试分块 64，通常较慢。

## 版本与系统限制

v0.1.1 为测试版。Windows 原生双击启动、文件夹选择器与显卡驱动兼容性没有完成实机验收。已有 Linux 软件 Vulkan 路径下的真实 AI 验证，不等同于 Windows 或每种 GPU 的保证。CPU 在已知测试环境失败，仅供实验。

如果图片只在游戏引擎里显得模糊或缩小时发花，请对照看图工具中的原 PNG，并检查纹理过滤、mipmap、导入压缩与实际显示尺寸。此工具不会修改游戏引擎设置。
