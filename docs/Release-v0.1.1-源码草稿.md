# 素材清晰工坊 v0.1.1 · Windows 测试版

本来在做自己的 SHO 桌游，结果中途多做了个软件。

我不是程序员，美术就让 GPT 帮忙画。单独打开看，还挺好看。结果往游戏里一放：放大糊，缩小又花。

有次明明要求 2048×2048，检查文件，实际只有 1254×1254。提示词里的“高清”，和文件里到底有多少像素，还真不是一回事。

于是我拉着 Codex，基于现有的开源 waifu2x 模型，做了个中文小工具，叫「素材清晰工坊」。

选一个文件夹，批量降噪、放大，长边可以统一到 2048，透明 PNG 也能处理。原图不动，处理完只输出成品。

功能没搞多复杂。就想解决一个问题：我有一堆游戏素材，总不能每张都手动折腾吧？

当然，AI 也不能凭空找回原图没有的细节，效果还得看素材。目前是 Windows 测试版，需要支持 Vulkan 的显卡。

游戏还没做完，工具先做出来了。独立开发，真是什么都得碰一点。

## 本次附件

本次准备的附件是源码 ZIP，不包含 Python 运行时、AI 引擎或模型，不能直接双击运行。源码运行步骤见仓库 README。
