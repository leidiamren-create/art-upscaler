# v0.1.1 验证范围

## 真实引擎验证

已用官方 waifu2x-ncnn-vulkan 20250915 Linux 引擎，在软件 Vulkan 设备 0 路径上验证真实神经网络推理。CUnet、温和降噪、目标长边 2048 的一次集成验证包含小图自检、坏图和透明 PNG：1536×1024 → 2048×1365，透明度范围 0–255，原图校验值不变。结果树只有正式 PNG，报告独立保存在工具日志目录。

这不是原生 Windows 验收，也不是对任意素材质量的承诺。仓库不附真实输入、输出、原始报告或设备路径。

## 仓库内可重复测试

`tests/` 仅使用测试时生成的合成图片和临时目录：

- 成功、部分失败、全部失败、取消、重新开始
- 原图与旧结果不变，子目录保留，正式 PNG 与日志分离
- 引擎自检失败不处理原图，日志写入失败不污染结果目录
- 本地接口的 Host、Origin 与访问令牌检查
- 移除旧预览路由，日志路径只能取自当前任务
- 尺寸计算、透明度、重复名称防覆盖、文件扫描与格式限制
- 前端脚本语法、DOM 标识、输出列表与错误文本转义、日志按钮和进度状态

流程测试使用替身引擎，不能替代真实 AI 推理测试。前端 DOM 测试不能替代完整浏览器视觉检查。
