# 素材清晰工坊 v0.1.1 测试版

## 本次变化

- 每张成功图片只输出一个正式 `*_AI.png`，保留子目录
- 移除前后对比图片及对比预览界面
- JSON / CSV 报告移到工具 `logs/`，新增“打开报告”按钮
- 原图、旧输出和已经生成的旧版对比图不会被自动删除或改写

AI 引擎、模型、默认温和降噪、长边 2048 的统一尺寸规则、原图保护和取消方式不变。原图比目标大时仍会等比例缩小。

## Windows 便携版

如果本次 Release 提供便携版附件，首次使用下载主程序、引擎和模型三包，解压到同一位置并合并 `ArtUpscaler` 文件夹。GitHub 自动生成的 Source code ZIP/TAR 仅是源码，不是便携安装包。

旧版用户若使用小更新包：先退出旧程序，将补丁内 `ArtUpscaler` 的文件复制到原工具目录并替换同名文件，再启动确认版本为 v0.1.1。模型与 Python 运行时无需重下。不要在程序处理图片时覆盖文件。

## 已知限制

- 面向 Windows 10/11 x64，需要 Vulkan GPU 与驱动，默认使用设备 0
- Windows 原生启动、文件夹选择器和显卡兼容性尚未完成实机验收
- CPU 是实验模式，已知环境中失败；没有自动 CPU 后备
- 目标长边 64–8192，静态 8 位图片；动画、多页、16 位/HDR 不支持
- 强降噪可能损失细节，请先试一张
